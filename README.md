# PDI Tech Leadership Copilot

Plataforma web moderna para líderes de tecnologia acompanharem evolução de carreira, PDI, feedback contínuo, performance e competências com suporte de IA.

## Entregáveis

- Arquitetura da solução (`docs/01-solution-architecture.md`)
- Wireframes principais (`docs/04-wireframes.md`)
- Estrutura de banco (`docs/02-database-schema.sql`)
- Fluxos de usuário (`docs/03-user-flows.md`)
- Especificação das telas (`docs/05-screen-specs.md`)
- Dashboard executivo (`docs/06-executive-dashboard.md`)
- Estratégia premium e escalável (`docs/07-scalability-enterprise.md`)

## Stack sugerida

- **Frontend:** Next.js + React + TypeScript + Tailwind + shadcn/ui
- **Backend:** NestJS (Node.js)
- **Banco:** PostgreSQL
- **Auth:** OAuth (Google + Microsoft Entra ID)
- **Infra:** AWS ou Azure
- **IA:** OpenAI API para copiloto do gestor

## Diferencial

Experiência focada no dia a dia de líderes de engenharia: decisões rápidas, visão clara dos riscos de carreira, ações de desenvolvimento e promoção orientadas por evidências.
