# 04. Wireframes Principais

> Wireframes de baixa fidelidade para orientar prototipação no Figma.

## 1) Dashboard do Gestor

```text
+--------------------------------------------------------------------------------+
| Topbar: Busca | Time | Alertas | Perfil                                       |
+--------------------------------------------------------------------------------+
| KPI Cards: [PDI em dia] [Atrasados] [1:1 semana] [Risco retenção] [Promoções] |
+--------------------------------------------------------------------------------+
| Heatmap 9-box (Performance x Potencial)     | Alertas Prioritários             |
|                                              | - João: PDI atrasado 14 dias     |
|                                              | - Ana: feedback pendente          |
+--------------------------------------------------------------------------------+
| Evolução por colaborador (sparklines)        | Próximas 1:1                     |
+--------------------------------------------------------------------------------+
| Tabela: Nome | Senioridade | PDI | Skills Gap | Próximo passo | Ação rápida    |
+--------------------------------------------------------------------------------+
```

## 2) Perfil do Colaborador

```text
+--------------------------------------------------------------------------------+
| Nome | Cargo atual | Senioridade | Tempo na função | Objetivo de carreira         |
+--------------------------------------------------------------------------------+
| Tabs: [Resumo] [PDI] [Feedback] [Skills] [1:1] [Promoção] [Histórico]         |
+--------------------------------------------------------------------------------+
| Resumo executivo IA                                                              |
| - Principais avanços                                                             |
| - Riscos atuais                                                                  |
| - Próximas ações recomendadas                                                    |
+--------------------------------------------------------------------------------+
| Timeline (movimentações + marcos de evolução)                                   |
+--------------------------------------------------------------------------------+
```

## 3) Tela de PDI

```text
+--------------------------------------------------------------------------------+
| Cabeçalho: Status do PDI | % progresso | Última revisão | Próxima revisão           |
+--------------------------------------------------------------------------------+
| Objetivos SMART: Curto | Médio | Longo                                            |
| [Objetivo] [Métrica] [Prazo] [Status] [Responsável]                              |
+--------------------------------------------------------------------------------+
| Ações práticas                                                                     |
| [ ] Concluir curso X (Empregado) - 30/05                                         |
| [ ] Liderar projeto Y (Gestor) - 20/06                                           |
+--------------------------------------------------------------------------------+
| Sugestões IA: ações de desenvolvimento + trilhas recomendadas                    |
+--------------------------------------------------------------------------------+
```

## 4) 1:1 e Career Talk

```text
+--------------------------------------------------------------------------------+
| Próxima 1:1: 12/05 14:00 | Preparar pauta | Exportar notas                       |
+--------------------------------------------------------------------------------+
| Pauta sugerida IA                                                                  |
| 1. Progresso do PDI                                                                |
| 2. Bloqueios técnicos                                                              |
| 3. Engajamento e motivação                                                         |
+--------------------------------------------------------------------------------+
| Notas da conversa | Compromissos | Follow-up                                     |
+--------------------------------------------------------------------------------+
```

## 5) Promoção e Sucessão

```text
+--------------------------------------------------------------------------------+
| Caso de promoção: Colaborador | Nível atual -> proposto | Status                |
+--------------------------------------------------------------------------------+
| Critérios objetivos por nível (checklist com evidências)                         |
+--------------------------------------------------------------------------------+
| Radar de competências | Score de prontidão | Parecer RH | Decisão liderança      |
+--------------------------------------------------------------------------------+
| Sucessão: cargo crítico | sucessor 1 | sucessor 2 | prontidão | risco             |
+--------------------------------------------------------------------------------+
```
